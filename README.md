# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## How to Play

1. Open `index.html` in any web browser.
2. Player **X** goes first — click any cell on the 3×3 grid to place your mark.
3. Players alternate turns (X → O → X → ...).
4. The first player to get **3 marks in a row** (horizontally, vertically, or diagonally) wins!
5. If all 9 cells are filled with no winner, the game ends in a **draw**.
6. Click **Restart Game** to play again. The scoreboard keeps track across rounds.

## Features

- Two-player gameplay (X vs O)
- Win detection with highlighted winning cells
- Draw detection
- Scoreboard tracking wins and draws
- Responsive design (works on mobile)
- Restart button to play multiple rounds

## Tech Stack

- **HTML** — Game structure
- **CSS** — Styling and animations
- **JavaScript** — Game logic
